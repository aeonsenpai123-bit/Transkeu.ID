# ui-ux-pro-max

UI/UX Pro Max v2.15.0 by nextlevelbuilder (MIT, see LICENSE), packaged as a Cowork plugin.

Skills:

- **ui-ux-pro-max**: main skill. Design system recommendations, UX and accessibility rules, stack guidelines, via a local Python search script (no dependencies).
- **design-system**: design tokens and token validation.
- **ui-styling**: shadcn/ui and Tailwind styling guidance.
- **brand**: brand guidelines and brand-to-token sync.
- **design**: logo, icon and corporate identity design. Image generation needs your own GEMINI_API_KEY (or ATLASCLOUD / MUAPI key); nothing is sent without a key.
- **banner-design**, **slides**: banner and HTML slide guidance.

Changes from the original repo: skills moved from `.claude/skills/` to `skills/` (script paths updated), test folders removed. Skill text is otherwise unchanged.
